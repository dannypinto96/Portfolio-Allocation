# Portfolio Asset Allocation Tracker

A modern web application to track and visualize your investment portfolio asset allocation with interactive pie charts and detailed metrics.

## Features

- 📊 **Interactive Pie Chart**: Visualize your asset allocation by category
- 💰 **Portfolio Metrics**: Track total value, number of assets, and categories
- 📈 **Category Breakdown**: Detailed table showing value and percentage for each category
- 💾 **Local Storage**: Your data is automatically saved in your browser
- 🎨 **Modern UI**: Beautiful, responsive design with Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to the URL shown in the terminal (typically `http://localhost:5173`)

### Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

## Usage

1. **Add Assets**: Enter the asset name, value, and category in the form
2. **View Allocation**: See your portfolio visualized in the pie chart
3. **Track Metrics**: Monitor your total portfolio value and allocation percentages
4. **Manage Assets**: Delete assets by clicking the × button

## Technologies Used

- React 18
- Vite
- Recharts (for charts)
- Tailwind CSS (for styling)
